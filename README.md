# Tweebbo for PlayStation Vita

Play in the same hotel as [tweebbo.lol](https://tweebbo.lol). Build rooms, chat with friends, collect furniture and pets, and play games with people on the web and other consoles.

**[Download for PlayStation Vita](https://github.com/Tweebbo/Tweebbo-Vita/releases/latest)** · [Release notes](RELEASE.md)

## Install

You need a PlayStation Vita with homebrew enabled (HENkaku or Enso).

1. Download `tweebbo.vpk` from the latest release.
2. Copy it to your Vita using USB or FTP.
3. Open VitaShell, select `tweebbo.vpk` and install it.
4. Launch Tweebbo from the LiveArea and connect to the internet. Offline play is also available.

## Controls

| Control | Action |
| --- | --- |
| Left stick | Walk |
| Cross | Talk, use furniture or confirm |
| Circle | Open rooms, close or cancel |
| Triangle / Square | Chat / wave |
| D-Pad | Walk, navigate lists or move furniture while placing |
| L / R | Zoom out / in: whole room, standard, close-up; turn pages in windows; rotate or change height while placing |
| Right stick up/down | Open Tools in the room; change catalogue section or Navigator page |
| START | Quit |

The room shows a button legend in the top-left corner. In Chat, L/R shows older/newer messages. Support is in the bottom toolbar and Tools.

Tap the floor to walk, a player to open their menu, or furniture to open its actions. The bottom toolbar and windows also respond to touch.

## Progress and updates

Use your private character code to play with the same character on the web and other consoles.

Tweebbo offers Update now when a newer release is available. You can also check from Help → Search for updates. The updater resumes interrupted downloads, verifies the SHA-256 and saves the VPK to `ux0:data/Tweebbo/tweebbo.vpk`. Open VitaShell and install it over the old version.
