# Tweebbo for PlayStation Vita 1.4.8

Optional furniture loading fix. Keep playing and update whenever convenient.

- Furniture textures retry after a temporary loading failure instead of staying invisible for the rest of the session.
- Furniture memory use is measured from the actual texture allocation, helping the cache stay within its memory budget.
- Existing rooms, furniture and saved characters are kept.
- Smaller updates are available from supported installed versions, with the complete VPK as fallback.

Install the verified VPK with VitaShell. Automated cache checks and native builds pass. Physical-console installation and performance acceptance remain pending.
